# ComicAPNG

ComicAPNG 是一款跨平台、以文档为中心的页面图像应用，用于创建、编辑、导出、提取和阅读 APNG 文档。本地图像、压缩包和来源模块提供的资源都会进入同一个可编辑文档模型，并共享一致的产品流程。应用支持 Windows、Linux 和 macOS。

```text
本地文件 / 压缩包 / 来源模块
              |
              v
         统一文档模型
              |
              v
     编辑 / 阅读 / 文档服务
              |
              v
    APNG / ZIP / 未来格式
```

## 主要功能

- 从图片或目录创建 APNG 漫画。
- 在同一个“创建 / 编辑”页面中导入已有 APNG 或 ZIP，并可继续添加图像和调整页面。
- 通过已安装的来源模块发现资源，并将页面与可选来源元数据转换为普通可编辑文档。
- 导出 APNG，或导出包含原始图像与版本化 `metadata.json` 的简单 ZIP 压缩包。
- 提取普通 PNG 或 APNG 中的页面。
- 使用单页或双页模式阅读 APNG 漫画。
- 选择封面、拖动调整页面顺序，并可一次选择多页进行管理。
- 将所有页面放入统一尺寸的固定画布。
- 按比例适配并保留完整图片内容；空余区域保持透明。
- 分别设置封面和正文页面时长，界面使用三位小数的秒数。
- 编辑 EXIF、PNG 文本和自定义元数据。
- 提供简体中文和英文界面。
- 使用统一的深色主题。
- 记住窗口位置、普通尺寸和最大化状态；显示器变化时将窗口恢复到可见区域。

## 下载

稳定版本请从 GitHub 仓库的 **Releases** 页面下载。开发或测试版本可在 **Actions** 中选择一次成功的 **Build ComicAPNG** 运行，然后从 **Artifacts** 下载。

目前提供四种构建：

- Windows x64
- Linux x64
- macOS Intel
- macOS Apple Silicon

macOS 构建目前没有使用 Apple Developer ID 签名，也没有经过公证，因此首次打开时可能出现 Gatekeeper 提示。

构建和平台细节请参阅[技术规格（英文）](./tech-specs.md)。

## 使用方法：来源

1. 打开 ComicAPNG，在左侧选择“来源”，再选择一个可用的来源模块。模块状态可在“偏好设置”的插件面板中查看，也可以在那里启用或停用模块。
2. 使用模块提供的搜索或发现功能查找资源。可用的查询方式和元数据取决于模块实现。
3. 打开一个结果，检查模块提供的标题、作者、标签、简介和页面分组等来源元数据。
4. 选择需要物化的页面分组；执行所选操作时，模块开始获取资源。
5. 根据需要选择以下通用操作：
   - “下载所选章节”把物化后的普通图像保存到指定文件夹。
   - “在创建页中打开”把资源转换为常规可编辑文档。之后可调整顺序、删除页面、更换封面、修改时长与元数据，再手动导出。
   - “导出 ZIP”调用与创建 / 编辑页面相同的 ZIP 导出器。
   - “下载并打包”调用常规 APNG 写入器，可合并所选页面分组或分别输出。
6. 来源模块提供建议封面；进入创建页后可继续更换。

来源模块负责资源发现、来源元数据和资源物化。核心应用负责把结果转换为统一文档，并继续完成编辑与导出。JMComic 是随应用提供的一个内置来源模块，也是来源模块架构的一个实现示例；ComicAPNG 的产品边界是所有来源共享的统一文档模型。内置模块与外部插件是不同的扩展类型，外部插件支持属于未来架构阶段。架构细节请参阅[来源模块架构（英文）](./source-modules.md)。

## 使用方法：创建 / 编辑

1. 打开 ComicAPNG。
2. 在左侧选择“创建 / 编辑”页面。
3. 使用“添加图像”加入一个或多个图片文件，也可以导入整个目录或直接拖入文件；“导入 APNG”和“导入 ZIP”会把现有文档载入同一编辑模型。
4. 选择页面并拖动到任意插入位置以调整顺序；需要时可移除页面。右键单击页面可使用“上移”“下移”“移到顶部”和“移到底部”。位于边界时，菜单只启用可改变顺序的操作。
5. 选中一页并将其设为封面。APNG 导出会把封面恰好一次放在第 1 帧。
6. 设置封面和正文页面时长。新项目默认封面为 `10.000` 秒，正文为 `5.000` 秒，每次增减为 `1.000` 秒。
7. 根据需要设置阅读方向并编辑元数据。
8. 使用“导出 APNG”选择 `.apng` 或 `.png` 输出文件，或使用“导出 ZIP”创建普通图像加 `metadata.json` 的可检查压缩包。

导出时，每一帧都使用相同的画布尺寸。图片会按比例放大或缩小并居中，完整内容保持原有宽高比；不同宽高比留下的区域为透明像素。

从任意来源模块送入创建页后，页面与本地导入页面完全相同。来源页码用于建立初始顺序；一旦手动调整，创建页中的顺序就是唯一有效顺序，并在缩略图刷新、封面设置和元数据修改后保持不变。封面标记跟随具体页面，移动封面页会保留封面身份；APNG 导出仍按既有规则把封面放在第 1 帧。

开发者可使用以下命令生成 10 张尺寸、宽高比、颜色、图案和编号均明显不同的本地测试图片：

```sh
python scripts/generate_reorder_fixtures.py --output .tmp/reorder-fixtures
```

可以把输出目录直接导入创建页，也可以通过内置测试来源走完整的“来源 -> 在创建页中打开”流程。

导入 APNG 时，应用读取逻辑合成帧及其时长。可靠的 ComicAPNG 几何信息可恢复原始图像边界；普通 APNG 或无效几何信息保留完整画布，裁剪范围仅来自可信几何信息。专用“导入 APNG”操作要求动画控制块；静态 PNG 可通过“添加图像”使用。

仅包含图像的 ZIP 会按文件名自然排序导入。存在元数据时，页面文件名集合必须与压缩包中的全部受支持图像完全一致；任一文件缺失、改名或多出时，页面顺序、时长、几何、页面来源 ID 和封面引用会作为一组标记为不可信。差异对话框会列出找到、引用、缺少和未引用的文件，然后提供三种选择：导入可信的文档级/来源元数据、按纯图像导入，或取消并保留当前文档。详细格式参阅 [ZIP 交换格式](./zip-format.md)。

## 使用方法：提取 APNG

1. 打开 ComicAPNG 并选择“提取”页面。
2. 选择一个 PNG 或 APNG 文件，也可以将文件拖入窗口。
3. 选择输出目录。
4. 根据需要启用覆盖已有文件，或在可靠的 ComicAPNG 几何信息存在时恢复原始页面边界。
5. 单击“提取”。

默认输出文件依次为：

```text
1.png
2.png
3.png
...
```

基本提取依赖标准 PNG/APNG 结构，EXIF 和 ComicAPNG 私有元数据均为可选信息。当前解码器可读取的普通 APNG 文件同样可以提取。可靠几何信息用于恢复原始边界，其他输入保留完整画布。

## 使用方法：阅读 APNG

1. 打开 ComicAPNG 并选择“阅读”页面。
2. 选择一个 PNG 或 APNG 文件，也可以将文件拖入窗口。
3. 使用上一页、下一页、缩略图或页码输入框跳转。
4. 使用放大、缩小、适合页面、适合宽度或实际尺寸调整显示。
5. 根据漫画选择从左到右或从右到左的阅读方向，也可以切换单页、双页和全屏模式。

方向键会按照所选阅读方向前进或后退，`Page Up` 和 `Page Down` 也可翻页，`F11` 可切换全屏。应用会在外部设置中保存阅读位置，漫画文件保持原样。

当前阅读器采用手动翻页。帧时长作为 APNG 文件的动画信息保存在文档中。

## 元数据

基本的创建、提取和阅读功能依赖页面内容，元数据作为可选增强信息。

- EXIF 元数据可保存描述、作者、版权、软件、日期时间、用户注释以及自定义标签。
- PNG 文本元数据可保存发布者、标题或其他键值信息。
- ComicAPNG 私有元数据记录阅读方向、页面时长和页面几何信息，供支持这些信息的功能使用。

无元数据输入会按普通文档处理。格式错误的私有元数据会被忽略，有效页面仍可正常读取。

## 构建状态与开发版本

如需完整的预发布构建测试，请在 GitHub **Actions** 中打开 **Build ComicAPNG**，单击 **Run workflow**，选择 `main` 后运行。工作流会测试并构建四个平台，并将结果作为四个 Artifacts 提供。

发布候选版本使用 `vX.Y.Z-rc.N` 形式的标签，并自动创建 prerelease。稳定版本使用 `vX.Y.Z` 形式的标签，并从稳定标签对应的提交重新构建后创建正式 Release。

## 常见问题

- **macOS 阻止打开应用：** 当前构建未签名、未公证，请在确认下载来源可信后按照系统提示手动允许。
- **APNG 文件很大：** APNG 使用完整图像帧和无损压缩，页面多或分辨率高时文件可能明显增大。
- **无法打开输入文件：** 文件可能损坏、扩展名与实际内容不一致，或使用了当前 Pillow 版本不支持的格式。
- **Linux 无法运行：** 自动构建以 Ubuntu 22.04 为兼容基准，请在目标发行版上验证运行环境。
- **看不到元数据：** 元数据属于可选内容，页面可在无元数据时保持有效。
